NYSE Composite Market Trends & Data Quality

Python Time-Series EDA, Data Cleaning & Correlation Analysis

Project context

I analyzed historical NYSE Composite (NYA) market data to examine price distributions, long-term patterns and data-quality issues. The project combines data preparation with exploratory visualizations and correlation analysis.

The workflow uses Python with Pandas and NumPy for data preparation, Matplotlib and Seaborn for exploratory views, and Plotly for the correlation heatmap. Fields include dates, open, high, low, close and adjusted-close values; the market dataset also contains trading volume.

Analysis workflow

Prepare the data

Read Market.csv, select the NYA series, inspect data types and missing values, and compare dropping incomplete rows with forward filling.

Explore structure

Convert dates, derive calendar fields, inspect price distributions, and compare price measures through time-series and scatterplot views.

Review data quality

Flag unusual price relationships for inspection, then examine correlations across price and calendar variables.

Interpretation

The analysis links data-quality checks to visual interpretation. Distribution plots make the shape of historical price levels visible; scatterplots help locate unusual combinations of recorded values; the heatmap summarizes how the selected variables move together. These views support exploratory understanding of the dataset.
